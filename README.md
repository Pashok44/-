## 📝 Описание проекта

**Маркет** — это полнофункциональное web-приложение для электронной коммерции. Проект предоставляет интуитивно понятный интерфейс для покупателей и мощные инструменты управления для администраторов.

### Цели проекта:
- ✅ Удобный каталог товаров с фильтрацией
- ✅ Безопасная регистрация и авторизация
- ✅ Полный цикл оформления заказа
- ✅ Админ-панель для управления контентом

---

## ⚙️ Функциональные возможности

### 👤 Для пользователей

#### 📦 Каталог товаров
- Просмотр категорий и карточек товаров
- Поиск по названию и описанию
- Фильтрация по цене, бренду и наличию

#### 🔐 Личный кабинет
- Регистрация и вход (JWT)
- История заказов со статусами
- Управление адресами доставки

#### 🛒 Корзина и заказы
- Добавление/удаление товаров
- Изменение количества
- Оформление заказа (выбор оплаты и доставки)

### 🛠️ Для администраторов

#### 📊 Панель управления
- CRUD операции с товарами и категориями
- Управление заказами (смена статусов)
- Просмотр статистики продаж

### 🔄 Системные функции
- ⚡ Асинхронная отправка email-уведомлений
- ⚡ Кэширование запросов (Redis)
- ⚡ Фоновая генерация отчетов
