> Сервис для продажи Электро-мотоциклов

---

Современное веб-приложение (SPA) для салона по продаже и аренде электрических мотоциклов. Проект демонстрирует удобный каталог техники с фильтрацией, систему бронирования тест-драйвов и адаптивный интерфейс.

## 🚀 Особенности

- **Каталог электромотоциклов** – карточки товаров с характеристиками (запас хода, мощность, время зарядки)
- **Умная фильтрация** – поиск по цене, дальности пробега и типу батареи
- **Бронирование тест-драйва** – выбор даты и времени с отправкой заявки
- **Калькулятор лизинга/кредита** – расчёт ежемесячного платежа онлайн
- **Адаптивная вёрстка** – корректное отображение на мобильных, планшетах и ПК
